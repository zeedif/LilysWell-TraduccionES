# Lily's Well - Traducción al Español

Parche de traducción al español para *Lily's Well* (RPG Maker MV, Steam). Toma como base la traducción de Gross, corrige los fallos que esa traducción había introducido, entre ellos el del final "Ma", y completa los menús que se habían quedado en inglés.

## Instalación

Copia todos los archivos de este repositorio dentro de `www` en tu instalación de Steam, reemplazando los archivos existentes:

```
...\steamapps\common\Lily's Well\www
```
